# Scripts and supplementary data for the manuscript 'Haplosufficient intronic and exonic knockouts of *vgsc* in *Anopheles gambiae*'

## Contents

### Analysis and Figure Scripts

*vgscKOFiguresClean.ipynb*

Jupyter notebook, contains code for:
* Figure 1B-F
* Figure 3 (LC bar plots only)
* Supplementary Figure for optimum screening age of *vgscKO*

*vgscKOInsecticideTesting.md*
Rmarkdown, contains code for:
* Bottle assay GLMs and model checks, with emmeans post-hoc testing
* Prediction table generation and plotting from GLMs
* LC table generation

*vgscKOLarvalSurvival.md*
Rmarkdown, contains code for:
* Binomial GLMM for larval survival data and model checks
* Hazard ratio calculation, survival prediction table generation and plotting from GLMM

*vgscKOanalysis.md*
Rmarkdown, contains code for:
* GLMs for egg laying, larvae number and hatch rate, with model checks and emmeans post-hoc testing
* Likelihood analysis for homozygotes in group lays
